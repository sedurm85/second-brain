# 세컨드브레인 2차 기획: 살아 움직이는 비서 (2026-09-30 초안)

1차(v0.5.1)는 "내 기록과 자동화를 한 화면에서 보는 비서". 2차는 비서의 역할을 전부 가져온다.
목표 문장(아침 7시 카톡 = 대시보드 첫 화면):
> "오늘 10시 팀 주간회의 전에 지난주 결정 두 건을 다시 보세요. 오후 3시 치과는 2시 20분에 나가면 됩니다. 답장 기다리는 메일이 2통, 다음 주 대만 여행 예약은 호텔만 남았어요."

## 원칙
1. 내 컴퓨터 안에서: 맥 캘린더·메일 앱에 붙은 계정을 EventKit/JXA로 읽기. 클라우드 OAuth·API 키 없음. 인증 정보는 볼트 밖.
2. 읽기는 자동, 쓰기는 확인: 일정 생성·메일 발송은 초안 → 사장님 확인 → 기록.
3. 문장으로 보고: 첫 화면은 여전히 두세 문장, 그 아래 시간표·카드.

## 여섯 역할
1. 시간(캘린더): 오늘 시간표·이번 주·다가오는 3주, 겹침·이동 부족 경고, 질문 응답, 일정 초안.
2. 할 일: inbox.md 확장(`@due(날짜)` `@someday` `@waiting(누구)` `@since`), 결정 D-N·크론 실패·답장 대기가 자동 유입, 아침 3개 제안, 미리알림 양방향(선택).
3. 메일: 답장 필요 / 기다리는 답 / 알아두면 됨. 예약 확인 메일 → plan 노트. 요약은 로컬 규칙, Claude 요약은 요청 시만. 발송은 초안까지.
4. 계획(plan 타입: trip|event|move|project-plan): 날짜별 동선(출발·수단·소요·지도), 예약 항목, 체크리스트(D-7/D-1), 당일 「오늘」에 동선 표시, 항공권 모니터 연결.
5. 미팅: 30분 전 브리핑 카드(참석자 people 노트·관련 결정·지난 회의록), 회의 후 캡처 → 후속 할 일, 정기회의 차이 요약.
6. 먼저 말하기: 아침 7시 브리핑, 출발 알림, D-N 알림, 답장 3일 초과, 저녁 마감 대화. 채널은 기존 카톡 헬퍼.

## 소스
| 소스 | 방법 | 판단 |
|---|---|---|
| 캘린더 | 맥 캘린더 앱 계정 EventKit(JXA) 읽기 | 로컬 · 어떤 계정 붙어 있는지 확인 |
| 메일 | 맥 메일 앱 JXA 읽기, 없으면 IMAP 앱 비밀번호(키체인) | 로컬 · 메일 앱 사용 여부 확인 |
| 회사 메일·캘린더 | 기술은 같음 | **기본 제외**, 정보보안 정책 확인 뒤 별도 결정 |
| 할 일 | inbox.md + 미리알림(선택) | 로컬 |
| 이동 시간 | 1단계 수동 입력, 2단계 지도 API 선택 | 외부 API 허용 여부 확인 |
| 알림 | notify_kakao.py | 있음 |

Claude에 보내는 내용은 대화에서 요청한 것만. 일정·메일 원본은 볼트에 복사하지 않고 `~/.cache/second-brain/`에 하루치 캐시.

## 볼트 확장
- 새 타입 `plan` (frontmatter: kind, start, end, people, status preparing|ongoing|done; 본문: 체크리스트 + 날짜별 동선)
- inbox 문법: `- [ ] 내용 @due(2026-10-02)`, `@someday`, `@waiting(세무사) @since(2026-09-28)`
- people 노트 자동 갱신(마지막 만남·관련 결정), meeting 노트에 `event_id` 링크
- API: `/api/agenda`, `/api/tasks`, `/api/mail`(묶음별 개수·제목만), `/api/plans`, `/api/brief`

## 대시보드
첫 화면: 보고 문장 + 오늘 시간표 한 줄(지금 위치) + 「지금 볼 것」(할 일·메일·자동화 통합) + 다가오는 계획 D-N 카드.
새 섹션: 이번 주(7일 격자), 할 일(4열), 메일(3묶음, 제목·발신만, 클릭 → 메일 앱), 계획(카드→날짜별 동선), 미팅 준비.
그래프: 사람·프로젝트·결정·회의·계획 연결, 참석자 클릭 시 주변 강조.
1차 킵 「지금 실행」: 4단계에서 할 일 체크·자동화 실행/멈춤/재시작과 함께(로컬 토큰 + allow_commands).

## 로드맵
1. **시간** (v0.6.0에서 구현, 2026-09-30. 남은 것: 구글 비공개 ICS 등록과 7시 크론 승인): EventKit 어댑터, /api/agenda, 시간표, 이번 주, 보고 문장에 일정, `brain.py brief --kakao` 아침 7시 크론. 완료 기준: 아침 카톡 한 통에 일정·할 일·자동화가 다 있고 대시보드와 같다.
2. **할 일과 계획** (일부 앞당김 v0.7.0: 일정 노트=메모·준비 체크리스트·상세 패널·쓰기 API. 남은 것: inbox 문법, plan 동선 겹침, 출발 알림): inbox 파서, 할 일 4열, D-N·크론 실패 유입, `brain-plan` 스킬, 당일 동선 겹침, 출발 알림. 완료 기준: 다음 여행을 plan으로 넣고 첫날 아침 카톡에 동선이 온다.
3. **메일과 미팅**: 메일 앱 어댑터, 3묶음 분류, 예약 메일→plan, 미팅 30분 전 카드, 회의 후 캡처→할 일, 답장 3일 초과 알림. 완료 기준: 미팅 전 카드 한 장, 저녁에 미답장 수를 안다.
4. **쓰기**: 일정 초안→확인→기록, 답장 초안→메일 앱 초안, 대시보드 체크·실행 버튼, 저녁 마감 대화. 완료 기준: 클릭으로 하루를 닫고, 비서의 쓰기는 전부 확인 거친 것.
